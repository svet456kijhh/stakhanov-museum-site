# Сайт музея Стаханова

Демонстрационный сайт. Запись на посещение работает в режиме подготовки текста заявки без отправки данных.

## Как редактировать в Яндекс Браузере

1. Войдите в аккаунт GitHub, которому принадлежит этот репозиторий.
2. Откройте [главную страницу сайта для редактирования](https://github.com/svet456kijhh/stakhanov-museum-site/edit/main/index.html). Меняйте тексты между HTML-тегами, не удаляя сами теги. Нажмите **Commit changes** и подтвердите сохранение.
3. Для текстов рубрик откройте [site.js](https://github.com/svet456kijhh/stakhanov-museum-site/edit/main/site.js). Для оформления — [styles.css](https://github.com/svet456kijhh/stakhanov-museum-site/edit/main/styles.css) и [gallery.css](https://github.com/svet456kijhh/stakhanov-museum-site/edit/main/gallery.css).
4. Чтобы добавить или заменить фотографии, откройте [папку assets](https://github.com/svet456kijhh/stakhanov-museum-site/tree/main/assets) и используйте **Add file → Upload files**. При замене изображения сохраните прежнее имя файла либо исправьте ссылку `src` в `index.html`.
5. Подождите несколько минут после сохранения и обновите опубликованный сайт в браузере. Если браузер показывает прежнюю версию, нажмите **Ctrl+F5**.

Изменения в GitHub доступны всем посетителям сайта после автоматической публикации. Для правок нужны права записи в этот репозиторий; посетители сайта не могут менять опубликованные материалы. Перед публикацией фотографий проверяйте разрешение правообладателя и необходимость согласия изображённых людей. Онлайн-отправка заявок пока не включена.
